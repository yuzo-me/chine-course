# Небольшая задача для Codex (когда у Claude Code закончился лимит)

Подходит для: юнит-тестов, изолированного модуля в `web/src/domain/`, исправления конкретного замечания. **Не подходит** для: интерфейса из многих экранов, изменения структуры данных, настройки хостинга.

---
Ты сейчас выступаешь разработчиком, а не ревьюером. Выполни задачу T-XX (или её часть: <опишите часть>) по правилам AGENTS.md, раздел «Если тебе дали задачу на реализацию», и CLAUDE.md.

1. Прочитай CLAUDE.md, docs/10-архитектура.md и карточку задачи в tasks/.
2. Сначала кратко перескажи план на русском и дождись моего «Да».
3. Ветка task/T-XX, маленькие коммиты, тесты обязательны, все проверки из CLAUDE.md §6.
4. Отчёт в reports/T-XX-отчёт.md, push ветки. В main не сливай.
---

После этого ревью делает **Claude Code** (поменяйтесь ролями): попросите его выполнить AGENTS.md «Как делать ревью» и записать `reports/T-XX-ревью-claude.md`.
