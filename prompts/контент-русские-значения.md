# Генерация русских значений (T-05, Claude Code)

Этот текст используется внутри задачи T-05. Claude Code обрабатывает слова партиями по 50.

---
Сгенерируй русские значения для слов HSK 1 из content/data/hsk1.raw.json, партиями по 50 слов (6 партий). Требования к каждому слову:

1. Значение — для ученика уровня HSK 1, русскоязычного, школьника или взрослого.
2. Сначала самое частотное значение именно в употреблении на уровне HSK 1. Учитывай часть речи из исходной строки (pos) и скобочные пометы (sourceNote).
3. meaningsRu — от 1 до 3 значений, каждое 1–4 слова. meaningRuShort — одно главное значение до 25 символов (для карточки).
4. Для служебных слов (частицы, счётные слова, предлоги) — краткое пояснение функции в скобках, например: 吗 → «(вопросительная частица)», 个 → «(счётное слово, универсальное)».
5. Не придумывай редкие значения. Не меняй иероглифы и пиньинь — они из официального источника.
6. Если не уверен в значении — поставь в поле status.meaningConfidence значение "low" и коротко опиши сомнение в status.meaningNote. Эти слова учитель проверит первыми.

Сохрани результат в content/data/hsk1.meanings.json (ключ — id слова). После каждой партии запусти validate.py.

В конце составь список всех слов с meaningConfidence = "low" в отчёте.
