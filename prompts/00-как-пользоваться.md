# Как пользоваться готовыми текстами (промптами)

1. Откройте нужный файл.
2. Скопируйте текст **между линиями `---`**.
3. Замените `T-XX` на номер задачи (например, `T-03`).
4. Вставьте в Claude Code или Codex и нажмите Enter.

| Ситуация | Куда | Файл |
|---|---|---|
| Начать задачу | Claude Code | `claude-code-задача.md` |
| Сделать ревью | Codex | `codex-ревью.md` |
| Исправить замечания ревью | Claude Code | `claude-code-исправить.md` |
| Слить принятую задачу | Claude Code | `claude-code-слить.md` |
| Дать небольшую задачу Codex (когда у Claude Code лимит) | Codex | `codex-задача.md` |
| Сгенерировать русские значения (T-05) | Claude Code | `контент-русские-значения.md` |
| Сообщить об ошибке на сайте | Claude Code | `сообщить-об-ошибке.md` |
| Вечерний отчёт | Claude в проекте | `отчёт-дня.md` |
| Инструкция для учителя | Учителю (мессенджер/почта) | `учитель-инструкция.md` |

**Важно:** запускайте Claude Code и Codex из папки проекта:
```
cd ~/Desktop/Chine_Course
claude      # или: codex
```
