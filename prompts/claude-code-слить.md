# Слить принятую задачу (Claude Code)

Использовать **только после** того, как Claude в проекте написал «T-XX ПРИНЯТО».

---
Задача T-XX принята. Слей ветку task/T-XX в main:
1. git checkout main && git pull
2. git merge --no-ff task/T-XX
3. Запусти все проверки из CLAUDE.md §6 на main. Если что-то не проходит — остановись и сообщи мне, не пушь.
4. git push
5. Отметь задачу T-XX как «Принята» в tasks/README.md, закоммить и запушь.
6. Скажи, когда сайт по постоянной ссылке обновится (Cloudflare Pages), и как это проверить.
