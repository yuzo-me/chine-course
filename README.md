## Ежедневный ритм (коротко)

1. Утром открываете `docs/02-план-недели.md` → берёте задачу дня из `tasks/`.
2. Запускаете задачу в Claude Code готовым текстом из `prompts/`.
3. Отдаёте результат на ревью в Codex готовым текстом из `prompts/`.
4. Проходите **чек-лист владельца** в карточке задачи (нажать → увидеть).
5. Пишете мне (Claude в проекте «zhonguwen»): «Проверь T-0X». Я читаю отчёт/код и принимаю или возвращаю.
6. Вечером — отчёт дня по шаблону `prompts/отчёт-дня.md`.

## Главные правила

- **Одна задача за раз.** Не начинать новую, пока текущая не принята.
- **Ничего не принимать без зелёных тестов и пройденного чек-листа.**
- **В четверг 12:00 — заморозка.** После неё только исправления.
- **В пятницу после 10:00 — никаких изменений.**
