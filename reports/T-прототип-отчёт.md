# Отчёт: прототип «Китайский · HSK 1»

## Что сделано (простыми словами)
Собран работающий сайт-тренажёр HSK 1 в новом стиле: кроваво-бордовый и слоновая кость, анимированный дракон на фоне, пагоды, ворота пайфан, фонари, китайская каёмка.
- **Данные из официального PDF HSK 3.0:** ровно 300 слов, 246 знаков для узнавания, 100 знаков для письма. Номера совпадают с индексом проекта, пропусков нет.
- **Русские значения** для всех 300 слов (подготовлены ИИ при создании контента; на сайте ИИ нет). Требуют проверки учителем.
- **Озвучка** 300 слов (голос Tingting из macOS), файлы работают офлайн. Требует проверки учителем.
- **Главная, Карточки** (переворот, 4 оценки, возврат «Не помню» в том же занятии, алгоритм FSRS), **Практика** (4 упражнения: иероглиф→значение, значение→иероглиф, ввод пиньиня `ni3`=`nǐ`, выбор тона; мгновенная проверка и разбор), **Словарь** (иероглиф, пиньинь с тонами/цифрами/без, по-русски), **Письмо** (анимация → с контуром → по памяти), **Прогресс**, **Настройки** (дракон вкл/выкл, новых слов в день), **резервная копия** файлом, **демо-режим**.
- Работает офлайн (PWA). Аккаунтов нет, личные данные не собираются.

## Как проверить владельцу (шаги «нажать → увидеть»)
1. Дважды щёлкните `Запустить сайт.command` в папке проекта (если macOS не пускает: правый клик → «Открыть»). Откроется сайт.
2. Главная: бордовый дизайн, летает дракон, внизу пагоды. «Начать учить» → карточки.
3. Карточки: «Перевернуть» (или пробел) → значение; клавиши 1–4 ставят оценку. «Не помню» → слово вернётся через 3 карточки.
4. Практика → «Ввод пиньиня»: напишите `cha2` для 茶 — засчитается. `cha1` — «Слог верный, тон неверный».
5. Словарь: введите `ni3`, `你`, `дочь`.
6. Письмо → 爱 → «Смотреть», потом «С контуром».
7. Прогресс → «Заполнить демо-данными» — числа появятся; «Сбросить» очищает. Там же выключатель дракона.
8. Выключите Wi-Fi после первого открытия опубликованной версии — сайт должен открываться (проверка на реальной публикации не сделана, см. ниже).

## Что не сделано или сделано иначе, и почему
- **Нет публикации** (Cloudflare Pages) и **нет GitHub-репозитория**: нужны ваши аккаунты, их создание и вход делает владелец. Папка — локальный git, коммиты есть.
- **Supabase не подключён.** Расходится с решением D-09 («нет аккаунтов, нет серверов») и с правилами проекта; нужно решить способ входа и защиту данных детей. Прогресс сейчас — в браузере + файл. См. D-19/D-20.
- **Не проверено на реальных iPhone/Android и в Safari (webkit)**; e2e только в Chromium. Страница проверки для учителя (P-12) не сделана — осталось в виде данных; учителю проще дать список слов (`content/data/meanings_ru.txt`).
- Поле `pinyinNumeric` из схемы архитектуры не включено (ошибалось для слитных слов); поиск считает его на лету.
- Вместо «Главная · Карточки · Практика · Словарь · Прогресс» навигация та же; «Письмо» вынесено внутрь Практики и главной.
- Дизайн-ТЗ про зелёную тему заменён решением D-17 (бордо + слоновая кость).
- Озвучка, значения — **не проверены учителем** (статус `generated`).

## Риски и слабые места
- Дракон нарисован кодом на холсте: на очень старых телефонах может греть; есть выключатель и автопауза (скрытая вкладка, «уменьшить движение»).
- Часть русских значений многозначна/упрощена (например, служебные слова) — нужна проверка учителем.
- Озвучка машинным голосом: тоны в слитных словах могут звучать неидеально.
- Ответ в упражнении на пиньинь сравнивает последовательность тонов, а не разбирает слоги по правилам — для слов HSK 1 этого достаточно.
- Закреплённым слово считается при интервале ≥ 14 дней (мой выбор, можно изменить).
