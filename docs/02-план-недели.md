## Если отстаём — что режем (строго по порядку)

1. Упражнение «выбор тона» (T-09 частично).
2. Экран прогресса → оставить счётчики на главной (T-13 частично).
3. Письмо без контура → оставить анимацию и письмо с контуром (T-11 частично).
4. Импорт резервной копии → оставить только экспорт.

**Не режем никогда:** данные и их проверку, карточки, словарь, озвучку, офлайн-открытие.
