# Актуальный комплект ТЗ

Для разработки нужны **оба ТЗ и папка с данными**.

1. [ТЗ приложения](ТЗ-приложение.md) — функции, полная автоматическая проверка ответов, база, программа HSK, экзамены, источники, карта 166 групп задач и приёмка.
2. [ТЗ дизайна](ТЗ-дизайн.md) — экраны, навигация, компоненты, состояния и визуальные правила.
3. [Данные для разработчика](Данные-для-разработчика/) — четыре вспомогательных файла: карта юнитов, индекс требований, экзаменационные профили и сведения об источниках.

[Скачать всё одним архивом](Актуальное-ТЗ.zip).

Версия требований — 1.1, с полностью автоматической проверкой ответов пользователей. Комплект упорядочен 6 ноября 2026 года. Старые имена файлов и дубли HTML/Markdown удалены из выдачи; требования и необходимые данные сохранены.
