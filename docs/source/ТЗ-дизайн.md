# Отдельное ТЗ на дизайн мобильного приложения

Версия 1.1 · 5 ноября 2026 года. Рабочее название: «Китайский · HSK». Название и бренд не утверждены.

## 1. Направление

Спокойная современная учебная среда с заметным ощущением продвижения. Главное визуальное содержание — китайский текст, понятная задача и следующий шаг. Игровой опыт присутствует как вторичный слой: небольшая полоса XP, уровни и достижения без шумных наград на каждом действии.

Все ответы проверяются автоматически. Статусы «Приложение проверяет ответ» и «Не удалось надёжно оценить — повторить» описывают обработку сервисом. Экранов ожидания преподавателя и ручного подтверждения нет.

Ключевой принцип: пользователь за несколько секунд понимает, что изучает, какой навык тренирует и что уже умеет. Дизайн поддерживает долгие занятия и не требует расходовать жизни, энергию или ждать следующего дня.

Первый интерфейс — русский. Китайский и пиньинь всегда различимы по размеру и роли. Компоненты заранее поддерживают более длинные переводы и другие письменности.

## 2. Архитектура навигации

Нижняя навигация, пять разделов:

| Раздел | Назначение |
|---|---|
| Учиться | Продолжить занятие, выбрать уровень и навык |
| Повторять | Карточки, ошибки и назначенные повторы |
| Словарь | Поиск слова/знака и встроенный переводчик |
| Экзамен | Выбор профиля, тренировка частей, полные пробники |
| Профиль | Учебные результаты, XP, загрузки и настройки |

Путь учебного контента: язык → программа → уровень → навык/все навыки → юнит → урок. Переключатель языка доступен в шапке главной. Версия программы видна на экране уровня и экзамена, но не перегружает каждый вопрос.

Внутри урока нижнюю навигацию скрыть. Выход через крестик с сохранением и, только при наличии несохранённого ответа, понятным выбором действия. Системная кнопка «Назад» работает ожидаемо.

## 3. Цвет и визуальная система

Предлагаемая светлая тема:

| Токен | Значение | Использование |
|---|---|---|
| Background | `#F6F7F4` | Основной фон |
| Surface | `#FFFFFF` | Карточки и панели |
| Text primary | `#17231F` | Основной текст |
| Text secondary | `#52635B` | Пояснения и метаданные |
| Primary | `#176B52` | Основное действие и выбранный раздел |
| Primary subtle | `#E5F2EA` | Мягкое выделение |
| Border | `#D5DED7` | Границы и разделители |
| Success | `#256B42` | Успех вместе с подписью/иконкой |
| Error | `#B42332` | Ошибка вместе с объяснением |
| Attention | `#785600` | Требует проверки/повторения |
| XP | `#6B4AA5` | Опыт и игровые достижения |

Цвета — стартовые токены. В итоговых макетах проверить контраст обычного текста не ниже 4,5:1, крупного и значимых графических элементов — не ниже 3:1. Бледный Border используется для декоративных разделителей; если граница необходима для распознавания поля, использовать более контрастный токен. Цвет не является единственным способом показать ответ или статус.

Тёмная тема: отдельные токены фона, поверхностей, текста и состояний, а не простая инверсия. Примерная основа — фон `#111916`, поверхность `#1C2822`, текст `#EEF5F0`; остальные пары подобрать и проверить. Не показывать ярко-белый холст письма в тёмной теме.

## 4. Типографика и сетка

Русский интерфейс — системный шрифт платформы; китайский — качественный шрифт с формами для упрощённого китайского. Не подставлять японские формы знаков. Пиньинь должен поддерживать все диакритики, включая сочетания с ü, и не обрезать верхние знаки.

| Роль | Базовый размер |
|---|---:|
| Заголовок экрана | 28 |
| Заголовок раздела | 22 |
| Основной текст | 17 |
| Подпись | 14 |
| Китайский в предложении | 24–28 |
| Слово на карточке | 48–64 |
| Один изучаемый знак | 96–128 |
| Пиньинь | 20–24 |

Размеры — независимые единицы интерфейса с системным масштабированием. Межстрочный интервал: 1,4–1,6 для пояснений, достаточный отдельный ряд для пиньиня. Не уменьшать китайские знаки ради помещения на одну строку; переносить выражение смысловыми частями.

Базовая сетка — 4; интервалы 8/12/16/24/32; боковые поля телефона 20, на узком экране 16. Минимальная интерактивная область 48×48. Кнопка основного действия — высота 52, радиус 16. Карточки — радиус 20; тень едва заметная или отсутствует. Ширина основного учебного столбца на планшете ограничена примерно 680, панели можно располагать рядом.

## 5. Экран D-01: первый запуск

Содержимое: короткое назначение приложения → «Китайский» → выбор начального уровня/«Начинаю с нуля» → «Пройти короткую диагностику» → «Продолжить без диагностики». Не показывать все настройки сразу.

Следующий экран загрузки объясняет, что текст и звук загружаются отдельно. Основное действие «Скачать стартовый пакет», рядом фактический размер. Без сети — возможность открыть уже включённый стартовый материал или повторить загрузку; не обещать работу отсутствующего пакета.

Состояния: первый запуск, восстановленный прогресс, сеть недоступна, недостаточно места, обязательная совместимость версии. Регистрация предлагается после появления сохраняемого прогресса или при включении синхронизации.

## 6. Экран D-02: главная

Иерархия сверху вниз:

1. Переключатель языка и программы.
2. Карточка продолжения: «HSK 2 · Поездки», цель следующего урока, основная кнопка «Продолжить».
3. Быстрый выбор навыка: аудирование, разговор, чтение, письмо, иероглифы, лексика/грамматика.
4. Карточка повторения: количество назначенных элементов и кнопка начала.
5. Компактная полоса XP и игровой уровень.

Не смешивать «уровень игрока» с названием HSK. Не показывать «HSK 2 освоен» по одному проценту пройденных экранов. Для нового пользователя главная предлагает первый урок, для вернувшегося — конкретную точку продолжения.

## 7. Экран D-03: уровень и зоны навыков

В шапке — HSK, редакция программы, краткая цель уровня. Ниже три показателя с подписями: пройдено материала, подтверждено навыков, результаты пробников. У каждого доступно объяснение расчёта.

Навыки — сетка плиток с понятными иконками и словами. Выбор плитки открывает список релевантных занятий и сохраняется при возврате. Кнопка «Все навыки» возвращает общий маршрут. Карточки доступны отдельным действием.

В списке юнитов: название, цель в одну строку, завершённость, слабые навыки и доступность загрузки. Свёрнутые группы допустимы; длинная декоративная игровая дорожка не должна мешать выбрать конкретный раздел.

Состояния: не начат, в процессе, пройден, нужен повтор, идёт автоматическая проверка, не скачан, ещё не опубликован. Неопубликованный уровень не выглядит как заблокированный платным тарифом.

## 8. Экран D-04: юнит

Показать: задачу общения, 3–7 конкретных целей подблока, уроки по навыкам, карточки, квиз и состояние проверки. Каждая строка урока содержит название и понятный результат, например «Понять время и место поездки».

Кнопка «Начать квиз» доступна для самопроверки; если материал ещё не изучен, предупреждение мягкое и однократное. Сдача квиза не означает автоматическое закрытие непроверенной речи. Внизу — сведения об объёме скачанных материалов и ссылка на повторение.

## 9. Экран D-05: упражнение

Верх: выход, название навыка, прогресс текущего занятия. Центр: одна задача, стимул и поле/варианты ответа. Низ: подсказка и фиксированная основная кнопка «Проверить» в пределах безопасной области.

Состояния вариантов: обычный, нажатый, выбранный, проверяется, верный, неверный, недоступный. До отправки выбранный вариант выделяется нейтрально; красный/зелёный появляются только после проверки. Ответ не отправляется случайным первым касанием, если формат предполагает отдельное подтверждение.

Проверка: короткий вывод → причина → правильный пример → «Далее». Верный ответ с содержательной подсказкой обозначается как выполненный с помощью. Ошибка не сопровождается резкими звуками, тряской экрана или потерей возможности заниматься.

Клавиатура не закрывает поле ввода или основное действие. Длинный текст прокручивается, вопрос остаётся доступен. Для перетаскивания существует альтернатива последовательными нажатиями.

## 10. Экран D-06: аудирование

Крупная кнопка прослушивания, состояние воспроизведения, при необходимости изображение и варианты. В учебном режиме — повтор и настройка скорости. Транскрипт и перевод скрыты до ответа; затем доступны раздельно.

В строгом экзамене используются ограничения профиля: недоступные элементы не просто серые, а отсутствуют или пояснены на подготовительном экране. Не показывать бегущие субтитры, если их нет в выбранном экзаменационном формате.

Ошибки: файл отсутствует, загрузка идёт, устройство без звука/аудиосессия прервана. Предложить повторное воспроизведение и проверку загрузки. Нельзя автоматически засчитывать ошибку ученику из-за несыгравшего файла.

## 11. Экран D-07: карточка с переворотом

Лицевая сторона: слово/знак по текущему направлению тренировки; никаких скрытых пиньиня и перевода, доступных экранному диктору. Озвучка — отдельная кнопка.

Оборот: пиньинь, значение по контексту, озвучка, короткий пример и переход к знаку/слову. Длинная статья открывается отдельно, карточка остаётся компактной.

После раскрытия — четыре подписанных действия: «Не помню», «Трудно», «Помню», «Легко». «Перевернуть» доступно отдельной кнопкой для клавиатуры и экранного диктора. Свайпы — дополнительный способ, не единственный.

Анимация переворота 180–240 мс; при уменьшении движения — мгновенная замена или короткое растворение. Во время озвучки карточка не переворачивается сама. Обе стороны объявляются как одно логическое содержимое без одновременного чтения скрытого ответа.

## 12. Экран D-08: иероглиф и письмо

Вверху — знак и контекстное чтение. Вкладки: «Значение», «Структура», «Писать». Ключ/компонент не выдаётся автоматически за доказанную этимологию; учебная мнемоника подписывается как мнемоника.

Холст письма занимает основное место: квадратная сетка, чёткая текущая черта, лёгкий контур при обучении. Кнопки «Показать», «Отменить черту», «Очистить», «Проверить». Размер холста не менее 240×240 на обычном телефоне, при увеличенном тексте доступен отдельный полноэкранный режим.

Этапы: посмотреть анимацию → повторить с контуром → повторить без контура → написать по памяти позже. Каждый этап явно подписан. При ошибке выделить конкретный компонент или черту и объяснить действие: «Начни горизонтальной чертой», а не только «Неверно».

Для обычного текстового задания показывать отдельное поле печатного ввода. Если оценивается рукопись, печатный ответ не подменяет её незаметно. При недоступном распознавании — самопроверка с образцом и соответствующим статусом.

## 13. Экран D-09: разговор

Показать задачу, материал и условия подготовки. Затем крупная кнопка записи, индикатор времени, остановка и возможность прослушать себя. До первой записи кратко пояснить необходимость микрофона.

Разбор разделить на содержание, связность, язык и произношение. Для автоматического результата показывать статус предварительности и доступную детализацию; не выводить заведомо точную оценку тонов по обычной расшифровке.

Состояния: подготовка, запись, воспроизведение, отправка, автоматическая проверка, результат, низкая уверенность, сеть отсутствует, микрофон запрещён. При низкой уверенности интерфейс предлагает повторить ответ; обращения к преподавателю или ожидания ручного решения нет. Пользователь не теряет запись при временном сбое. Отправка голоса внешнему сервису сопровождается понятным объяснением и настройкой хранения.

## 14. Экран D-10: чтение и грамматика

Для чтения — комфортный текстовый блок, вопрос и варианты. В обучении нажатие на слово открывает компактное пояснение, не уводя со страницы. Подсказки учитываются; в пробнике отключены.

Грамматика: цель → простое объяснение → схема → два контрастных примера → типичная ошибка → практика. Сначала показывать смысл, терминология доступна подробнее. Китайские примеры визуально отделены от русского объяснения, пиньинь включается по необходимости.

На старших уровнях текст и вопросы можно показывать рядом на планшете. На телефоне — удобное переключение с сохранением места; пользователь не должен постоянно терять исходный абзац.

## 15. Экран D-11: квиз и результаты

Перед началом: что проверяется, примерный объём, правила подсказок и повторов. После: учебная оценка, сильные навыки, слабые цели, статус открытых ответов, начисленный опыт и конкретные действия «Разобрать ошибки»/«Повторить слабые места».

Не показывать торжественную отметку «Освоено», пока идёт автоматическая обработка обязательной части. Если результат ниже порога, формулировка нейтральная: «Нужно закрепить две темы». Повторная попытка не требует оплаты/ожидания в рамках этого ТЗ.

## 16. Экран D-12: экзамен

До начала: версия HSK, уровень, письменный/устный профиль, формат симуляции, длительность, состав, способ оценивания, наличие необходимых медиа и отличие учебного результата от официального.

Во время: номер задания, раздел, допустимый остаток времени, ответ и навигация по правилам профиля. Переход раздела фиксируется; предупреждение об окончании времени спокойное. Таймер не меняет цвет постоянно и не воспроизводит тревожные сигналы каждую секунду.

Пауза разрешена только в учебной симуляции; она переводит результат в соответствующий статус. Прерывание строгого режима сохраняет историю, но не оформляет полноценный завершённый независимый вариант.

Отчёт: сырые результаты, баллы по подтверждённой или внутренней шкале с подписью, показатели частей, статус автоматической обработки, ошибки по целям, рекомендации и история пробников. «Готовность» не оформляется как официальный сертификат.

## 17. Экран D-13: словарь и переводчик

Один раздел с переключением «Словарь»/«Перевести». Поиск поддерживает иероглифы, пиньинь с диакритикой/цифрами и русский перевод по имеющемуся словарю. Во время ввода показывать локальные результаты; отсутствие сети не скрывает скачанный словарь.

Статья слова: написание, чтение по значению, перевод, примеры, звук, связанные знаки и учебные уровни. Сохранение в личные карточки — заметное действие. Текст перевода внешнего сервиса имеет собственную маркировку; слово не получает статус проверенного учебного материала автоматически.

Пустой результат предлагает проверить ввод или включить сетевой перевод. Не выдавать совпадение без тонов за однозначный ответ, если есть несколько чтений.

## 18. Экран D-14: загрузки, прогресс и настройки

Загрузки: пакеты текста/озвучки по уровням, фактический размер, состояние, доступное место и действия скачать/приостановить/удалить. Перед удалением пояснить, что прогресс сохранится. Критическое обновление контента объясняет причину и затронутые уроки.

Прогресс: отдельные навыки, материал, повторение и пробники; игровой XP ниже учебных показателей. Графики имеют текстовое представление. Уведомления добровольные; язык без обвинений за пропуск занятий.

Настройки: звук и скорость, пиньинь, размер текста, тема, движение, загрузка по мобильной сети, напоминания, синхронизация, голосовые данные, экспорт/удаление и сведения об источниках.

## 19. Административный интерфейс

Веб-панель ориентирована на работу с контентом. Слева — разделы; в центре — таблица/редактор; справа — предварительный просмотр мобильного представления и связи с требованиями. Для каждой записи видны редакция программы, источник, статус проверки и изменения.

Обязательные экраны: импорт с отчётом; матрица покрытия с фильтром пробелов; редактор урока; редактор задания и допустимых ответов; медиа и права; очередь рецензирования; предварительный просмотр пакета; публикация/откат. Перед публикацией выводятся конкретные блокирующие ошибки, а не один общий красный статус.

## 20. Общие состояния и доступность

Для каждого экрана проектировать: обычный, загрузка, пусто, ошибка, без сети, нет разрешения, частично доступно и завершение. Скелетон не имитирует уже готовый учебный текст; кнопка повтора не удаляет введённый ответ.

Экранный диктор получает названия кнопок и корректное состояние выбранного ответа. Порядок фокуса соответствует чтению. Пиньинь и китайский текст размечаются подходящими языками. Не раскрывать скрытые ответы через подписи изображений или скрытые элементы.

Увеличение текста до 200% сохраняет доступ ко всем действиям. При моторных ограничениях есть альтернативы перетаскиванию; письмо может оставаться отдельной целевой задачей с адаптированным режимом и честной отметкой способа ввода. Тексты/субтитры доступны в обучении после попытки; в проверке аудирования помощь меняет статус результата.

## 21. Комплект макетов и приёмка дизайна

Дизайнер передаёт: карту навигации; библиотеку компонентов с состояниями; цветовые и типографические токены; светлую/тёмную тему; макеты всех D-01–D-14; планшетные варианты чтения и письма; административные экраны; кликабельные сценарии; правила анимаций и адаптации; состояния ошибок и загрузок.

Обязательные прототипные сценарии: первое занятие; выбор отдельного навыка HSK 2; переворот и повтор карточки; письмо без контура; запись речи с отказом в разрешении; квиз и разбор; пробный экзамен; загрузка с обрывом; исправление/публикация материала владельцем.

Проверка с 5–8 представителями аудитории перед реализацией ключевых потоков: найти письмо HSK 2, начать урок, перевернуть карточку, различить XP и учебный уровень, определить непроверенный речевой результат, скачать/удалить звук. Цель пилота — не менее 80% успешных выполнений без подсказки для каждого основного сценария; при малой выборке это сигнал для доработки, не доказательство качества для всей аудитории.

Дизайн принят, если все сценарии представлены, статусы однозначны, китайский текст читаем, нет потери действий при масштабировании, помощь не раскрывает ответы в пробнике, а передача в разработку содержит размеры/токены/поведение. Этот документ задаёт дизайн; полноценные финальные макеты и их пользовательское тестирование являются следующей производственной работой.
