# Установка (суббота утром, 2–3 часа)

Это задача **T-01**. Делайте по шагам. На любой ошибке — **остановитесь и пришлите мне весь текст ошибки**. Не пытайтесь чинить наугад.

Как открыть терминал: `Cmd + Пробел` → набрать «Терминал» → Enter.
Команды копируйте целиком, вставляйте в терминал (`Cmd + V`) и нажимайте Enter.

## Шаг 1. Homebrew (установщик программ)

Проверка, есть ли уже:
```
brew --version
```
Если ответ «command not found» — установить:
```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```
Попросит пароль от Mac (символы при вводе не видны — это нормально). В конце установщик покажет 2–3 команды «Next steps» — **выполните их**.

## Шаг 2. Node.js, Python, Git, GitHub CLI

```
brew install node python git gh
```
Проверка (каждая команда должна показать номер версии):
```
node --version
python3 --version
git --version
gh --version
```
Node должен быть версии 20 или выше.

## Шаг 3. Настройка Git и вход в GitHub

```
git config --global user.name "Ваше Имя"
git config --global user.email "oblepihovvita@gmail.com"
gh auth login
```
В `gh auth login` выбирайте: **GitHub.com → HTTPS → Yes → Login with a web browser**, затем введите код в открывшемся браузере.

## Шаг 4. Claude Code

```
curl -fsSL https://claude.ai/install.sh | bash
```
Если не сработало — альтернатива:
```
npm install -g @anthropic-ai/claude-code
```
Проверка и вход (войдите аккаунтом с подпиской Pro):
```
claude --version
claude
```
Выход из Claude Code: набрать `/exit`.

## Шаг 5. Codex

Если Codex уже установлен — проверьте `codex --version` и пропустите шаг.
```
npm install -g @openai/codex
codex --version
codex
```
Войдите аккаунтом ChatGPT (подписка Plus).

## Шаг 6. Репозиторий на GitHub

В терминале:
```
cd ~/Desktop/Chine_Course
git init -b main
git add .
git commit -m "Стартовый комплект проекта"
gh repo create chine-course --private --source=. --push
```
Проверка: откройте https://github.com/ → в списке репозиториев есть `chine-course` с этими файлами.

## Шаг 7. Аккаунт Cloudflare (хостинг сайта)

1. Зарегистрируйтесь на https://dash.cloudflare.com/sign-up (бесплатно).
2. Пока больше ничего не делайте — подключение сайта настроим в задаче T-02 вместе с Claude Code.

## Шаг 8. Проверка, что всё готово

```
cd ~/Desktop/Chine_Course
claude
```
Вставьте в Claude Code:
```
Прочитай CLAUDE.md и README.md. Кратко на русском перескажи, что за проект, какие у тебя правила и какая первая задача. Ничего не меняй в файлах.
```
Если пересказ верный — установка завершена. Отметьте T-01 как «Готово» в `tasks/README.md` и пришлите мне: «T-01 готово».

1. Номер шага.
2. Команду, которую вводили.
3. **Полный** текст ответа терминала (скопировать всё, включая красные строки).
