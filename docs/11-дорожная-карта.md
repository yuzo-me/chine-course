# Дорожная карта после прототипа

Сроки — ориентир при 3–4+ часах в день, пересчитываются после первой недели по фактическому темпу.

| Этап | Что | Ориентир | Условие перехода |
|---|---|---|---|
| **0. Прототип** | Тренажёр слов и иероглифов HSK 1 | 7–13.11.2026 | Показ руководству |
| **1. Пилот прототипа** | 5–10 учеников курса, кнопка «Сообщить об ошибке», сбор отзывов | 2 недели | Нет блокирующих ошибок, ученики пользуются без помощи |
| **2. Полный HSK 1** | 15 юнитов по задачам syllabus, грамматика (стр. 386–388), примеры предложений, чтение, квизы юнитов, часть «Чтение» экзамена HSK 1, XP | +2–3 месяца | Каждое требование syllabus HSK 1 покрыто уроком и проверкой; учитель принял выборку |
| **3. Кабинет учителя** | Аккаунты учеников, синхронизация, прогресс группы для учителя | +1–2 месяца | Решение по серверу и защите данных несовершеннолетних |
| **4. HSK 2–3** | Тем же конвейером; письмо HSK 2 (компоненты, знак по пиньиню) | +1–2 месяца на уровень | Пилот каждого уровня |
| **5. HSK 4–6** | Тем же конвейером; объём слов растёт до 1 600–1 800 на уровень | +2–3 месяца на уровень | Учитель успевает проверять выборку |
| **6. Коммерческий запуск** | См. ниже | параллельно с этапами 3–4 | Все пункты ниже выполнены |

## Что нужно для продажи (не делать до решения руководства)

1. **Лицензии**: подтвердить права на списки HSK, данные черт, озвучку (`docs/08-лицензии.md`).
2. **Модель продаж**: доступ ученикам курса / подписка / продажа школам — решает руководство.
3. **Аккаунты и оплата**: сервер, платёжный провайдер, договор-оферта.
4. **Персональные данные**: политика конфиденциальности, согласие родителей для несовершеннолетних, требования законодательства страны продаж.
5. **Поддержка**: кто отвечает на вопросы пользователей и исправляет ошибки контента.
6. **Мобильные приложения** (по желанию): упаковка сайта в приложение для App Store / Google Play.

## Принципы, которые сохраняются на всех этапах

- Нет ИИ внутри продукта; ИИ — только при подготовке контента + проверка учителем.
- Контент — только в файлах данных, с валидаторами.
- Каждая задача: разработчик → независимое ревью → чек-лист владельца → приёмка.
