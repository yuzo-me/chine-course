## 3. Озвучка — решение на субботу (D-16)

| Вариант | Плюсы | Минусы | Что проверить |
|---|---|---|---|
| **А. Microsoft Azure Speech** (нейроголоса zh-CN) | Высокое качество, поддержка SSML (можно задать пиньинь явно — важно для 多音字), есть бесплатный лимит | Нужна регистрация и карта; ключ API | Условия использования сгенерированного аудио в распространяемом продукте |
| **Б. Google Cloud Text-to-Speech** | Высокое качество, SSML, бесплатный лимит | Регистрация и карта | То же |
| **В. Голос браузера (Web Speech API)** — запасной | Бесплатно, без файлов, без лицензий | Качество зависит от устройства; на части устройств нет китайского голоса или нет офлайн | — |

**Рекомендация:** А или Б для файлов (300 коротких слов укладываются в бесплатный лимит обоих — проверить при регистрации), В — запасной вариант, если в субботу не получится с регистрацией.
Ключ API хранится **только** в `.env.local` на вашем Mac, в репозиторий не попадает.
