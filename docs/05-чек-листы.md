# Чек-листы

Чек-лист каждой задачи — внутри её карточки (`tasks/`). Здесь — общие проверки.

## 1. Как запустить сайт у себя (для проверки задачи до слияния)

Попросите Claude Code: «Запусти сайт для проверки ветки task/T-XX и дай ссылку для компьютера и телефона».
Обычно это:
```
cd ~/Desktop/Chine_Course/web
npm run dev -- --host
```
Ссылка вида `http://localhost:5173` — для компьютера; `http://192.168.x.x:5173` — для телефона в той же Wi-Fi сети.
Остановить: `Ctrl + C` в терминале.
