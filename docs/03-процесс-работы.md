# Процесс работы

## Кто что делает

| Участник | Роль | Где работает |
|---|---|---|
| **Вы** | Владелец: запускаете задачи, проверяете поведение по чек-листу, принимаете решения | Терминал на Mac + браузер + телефон |
| **Claude Code** | Основной разработчик | Терминал, папка `Chine_Course` |
| **Codex** | Независимый ревьюер; иногда — небольшие задачи | Терминал, папка `Chine_Course` |
| **Claude в проекте «zhonguwen»** (этот чат) | Архитектор и контролёр: карточки задач, финальная проверка, решения по рискам, презентация | claude.ai |
| **Учитель** | Проверка слов, озвучки, письма | Ссылка на сайт + таблица |

**Главный принцип:** код проверяет не тот, кто его написал. Claude Code пишет → Codex проверяет → вы проверяете поведение → Claude в проекте принимает.

## Цикл одной задачи (7 шагов)

| Шаг | Кто | Что сделать | Готовый текст |
|---|---|---|---|
| 1 | Вы | Открыть терминал, `cd ~/Desktop/Chine_Course`, запустить `claude` | — |
| 2 | Claude Code | Выполнить задачу, написать отчёт, отправить ветку на GitHub | `prompts/claude-code-задача.md` |
| 3 | Вы | Открыть второй терминал, `cd ~/Desktop/Chine_Course`, запустить `codex` | — |
| 4 | Codex | Ревью, запись `reports/T-XX-ревью-codex.md` | `prompts/codex-ревью.md` |
| 5 | Claude Code | Если вердикт «ДОРАБОТАТЬ» — исправить замечания (повторить шаги 4–5, максимум 2 круга) | `prompts/claude-code-исправить.md` |
| 6 | Вы | Пройти **чек-лист владельца** из карточки задачи: локально (`npm run dev`) и/или по ссылке предпросмотра | — |
| 7 | Claude в проекте | Написать сюда: «Проверь T-XX». Я читаю отчёт, ревью и код. Если принято — вы даёте Claude Code команду слить | `prompts/claude-code-слить.md` |

После слияния в `main` сайт обновляется по ссылке автоматически (Cloudflare Pages).

## Если что-то пошло не так

| Ситуация | Что делать |
|---|---|
| Claude Code задаёт вопрос, на который вы не знаете ответ | Скопируйте вопрос сюда, в проект. Отвечу или приму решение вместе с вами |
| Ошибка при установке или командах | Скопируйте **весь текст ошибки** сюда |
| Codex и Claude Code спорят (2 круга не помогли) | Принесите оба файла сюда, решу я |
| Закончился лимит Claude Code | Небольшие задачи (тесты, мелкие исправления) отдайте Codex по `prompts/codex-задача.md`. Ревью таких задач делает Claude Code |
| Закончились лимиты у обоих | Работайте над тем, что без ИИ: чек-листы, общение с учителем, подготовка презентации |
| Задача не укладывается в день | Сообщите сюда до вечера — пересоберём план и решим, что резать |

## Правила git (их выполняет Claude Code, вам — только знать)

- `main` — всегда рабочая версия, её видят по ссылке.
- Каждая задача — своя ветка `task/T-XX`.
- В `main` попадает только принятая задача.
- Каждый вечер всё отправляется на GitHub, поэтому работа не потеряется, даже если сломается компьютер.

## Как я (Claude в проекте) проверяю работу

Папка `Chine_Course` подключена к этому чату — я читаю файлы напрямую. Если подключение пропадёт, добавьте репозиторий GitHub в чат.
Я проверяю:
1. Соответствие карточке задачи и ТЗ прототипа.
2. Отчёт Claude Code и ревью Codex — не пропущены ли замечания.
3. Выборочно код: ограничения продукта (нет ИИ/сервера/секретов), тесты реально проверяют поведение.
4. Данные: контрольные числа, выборка слов.

Вердикт: **ПРИНЯТО** или **ВЕРНУТЬ** со списком, что исправить.

## Отчёт дня

Каждый вечер — 5 минут по шаблону `prompts/отчёт-дня.md`, присылаете сюда. Я сверяю с планом и, если нужно, двигаю задачи на завтра.
