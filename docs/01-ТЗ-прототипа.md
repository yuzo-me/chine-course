# ТЗ прототипа «Китайский · HSK — тренажёр»

Версия 2.0-прототип · 6 ноября 2026. Основано на большом ТЗ v1.1 (`docs/source/`) с решениями из `docs/06-журнал-решений.md`.
При расхождении с большим ТЗ **действует этот документ**.

## 1. Цель

К **пятнице 13.11.2026** показать руководству школы работающий сайт-тренажёр слов и иероглифов HSK 1, который:
- открывается по ссылке на телефоне и компьютере;
- работает без интернета после первого открытия;
- учит без учителя: карточки, упражнения с мгновенной проверкой, письмо иероглифов, повторение по расписанию;
- выглядит аккуратно и понятно.

Прототип — **основа будущего продукта**, а не одноразовая демонстрация: код и данные дальше развиваются до полного HSK 1–6.

## 2. Пользователи

Ученики курса китайского (школьники и взрослые), у которых есть учитель. Аудирование и говорение ведёт учитель, поэтому их на сайте нет.

## 3. Входит в прототип

| Код | Функция | Описание | Приёмка (главное) |
|---|---|---|---|
| P-01 | Данные HSK 1 | 300 слов (иероглифы, пиньинь, часть речи, русское значение), 246 знаков для узнавания, 100 знаков письма группы 1–2 | Ровно 300 / 246 / 100, совпадают с индексом `docs/source/data/06-source-reference-index.csv` |
| P-02 | Озвучка слов | 300 mp3-файлов, заранее сгенерированы | Каждое слово звучит; учитель проверил |
| P-03 | Главная | Карточка «Продолжить», число повторов на сегодня, быстрый вход в разделы | Новый пользователь видит, с чего начать |
| P-04 | Карточки | Переворот, озвучка отдельной кнопкой, «Не помню / Трудно / Помню / Легко» | Озвучка не переворачивает карточку; оценка меняет дату повтора |
| P-05 | Повторение | Алгоритм FSRS, очередь «на сегодня» | После «Не помню» слово возвращается в той же сессии |
| P-06 | Упражнения | 3 типа: значение ↔ иероглиф (выбор), ввод пиньиня, выбор тона | Проверка мгновенная, разбор ошибки, ввод `ni3` = `nǐ` |
| P-07 | Словарь | Поиск по иероглифу, пиньиню (с тонами и цифрами), по-русски; статья слова | Результат ≤ 300 мс, работает офлайн |
| P-08 | Письмо | Анимация черт → письмо с контуром → без контура; проверка черт | Учитель пишет 10 знаков без ложных ошибок |
| P-09 | Прогресс | Изучено слов, выучено (закреплено), повторы на сегодня, написанные знаки | Числа совпадают с реальными действиями |
| P-10 | Офлайн и резервная копия | PWA; экспорт и импорт прогресса файлом | В режиме полёта сайт открывается и работает |
| P-11 | Демо-режим | Кнопка «Заполнить демо-данными» и «Сбросить» в настройках | Экран прогресса на показе не пустой |
| P-12 | Страница проверки для учителя | Список всех слов со звуком и полями для отметок | Учитель проверяет 300 слов за 2–3 часа |

## 4. НЕ входит в прототип (будет позже — см. `docs/11-дорожная-карта.md`)

Юниты по 15 темам и уроки · грамматика · примеры предложений и тексты для чтения · квизы юнитов · экзамен-симулятор · показатели готовности к HSK · XP и достижения · тёмная тема · аккаунты, синхронизация, кабинет учителя · оплата · HSK 2–6.

**Совсем не делаем (решение принято):** ИИ на сайте · аудирование · говорение и запись голоса · переводчик свободного текста.

## 5. Правила проверки ответов (без ИИ)

| Упражнение | Как генерируется | Как проверяется | Разбор ошибки |
|---|---|---|---|
| Иероглиф → значение (4 варианта) | Неверные варианты — случайные значения других слов HSK 1, по возможности той же части речи | Ключ | «Вы выбрали „X“ — это значение слова Y. Правильно: Z» |
| Значение → иероглиф (4 варианта) | Неверные варианты — слова со схожим видом или той же длины | Ключ | То же, с пиньинем выбранного слова |
| Ввод пиньиня | Показан иероглиф | Нормализация: `ni3`→`nǐ`, `v`/`u:`→`ü`, регистр, пробелы, апострофы; тон и слог проверяются отдельно | «Слог верный, тон неверный: нужен 3-й тон» |
| Выбор тона | Показан иероглиф + слог без тона, звук доступен | Ключ | «Это 4-й тон — падающий» |

Подсказка (показ пиньиня/значения) → ответ засчитывается как «с помощью» и не продвигает повторение как полностью верный.

| Показатель | Цель |
|---|---|

| ИИ на сайте | отсутствует |

- Пройден чек-лист устройств (`docs/05-чек-листы.md` §2).
- Сайт опубликован по постоянной ссылке.
- Подготовлены сценарий демонстрации и слайды (`docs/09-демо-и-презентация.md`).
- Известные ограничения записаны и будут честно названы на показе.
