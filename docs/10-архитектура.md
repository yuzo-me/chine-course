# Архитектура прототипа

## Схема

```
[официальный PDF syllabus] ──(content/scripts/import_hsk1.py)──► content/data/hsk1.raw.json
                                                                       │
            ИИ на этапе подготовки (T-05) ──► русские значения ────────┤
            TTS-сервис (T-06) ───────────► content/audio/*.mp3 ────────┤
            правки учителя (T-12) ───────► content/review/*.csv ───────┤
                                                                       ▼
                                   content/scripts/build.py ──► content/data/hsk1.json
                                   content/scripts/validate.py (обязателен перед каждым коммитом данных)
                                                                       │ копируется при сборке
                                                                       ▼
                    web/ (React + TS, статический сайт, PWA) ──► Cloudflare Pages
                                   │
                                   └── прогресс ученика: IndexedDB (Dexie) в браузере → экспорт/импорт JSON
```

Сервера нет. ИИ на сайте нет. Всё, что видит ученик, — статические файлы.

## Модель данных контента (`content/data/hsk1.json`)

```json
{
  "schemaVersion": 1,
  "curriculum": { "id": "hsk3.0", "edition": "2025-11/2026-07", "sourceSha256": "d8b66465…" },
  "words": [
    {
      "id": "HSK-V00001",
      "level": "1",
      "officialSerial": 1,
      "hanzi": "爱",
      "pinyin": "ài",
      "pinyinNumeric": "ai4",
      "pos": ["动"],
      "sourceNote": "",
      "meaningsRu": ["любить"],
      "meaningRuShort": "любить",
      "audio": "audio/HSK-V00001.mp3",
      "chars": ["爱"],
      "status": { "meaning": "generated", "audio": "generated", "reviewedBy": null, "reviewedAt": null },
      "sourcePage": 80
    }
  ],
  "charactersRecognition": [
    { "id": "HSK-1-character_recognition-0001", "char": "爱", "officialSerial": 1, "sourcePage": 356 }
  ],
  "charactersWriting": [
    { "id": "HSK-1-2-character_handwriting-0001", "char": "…", "officialSerial": 1, "group": "1-2", "sourcePage": 377 }
  ]
}
```

`id` слов и знаков совпадают с `reference_id` из `docs/source/data/06-source-reference-index.csv` — по ним идёт сверка.
Статусы: `generated` → `reviewed_ok` → `fixed` (исправлено по замечанию учителя).
Значения выше — пример формата, не проверенные данные.

## Модель прогресса ученика (IndexedDB)

| Таблица | Поля | Назначение |
|---|---|---|
| `cards` | `id` (`wordId:direction`), `wordId`, `direction` (`hanzi2meaning` / `meaning2hanzi`), FSRS-состояние (`due`, `stability`, `difficulty`, `reps`, `lapses`, `state`, `lastReview`) | Расписание повторений |
| `reviewLog` | `id` (uuid), `cardId`, `rating`, `reviewedAt`, `source` (`cards`/`exercise`), `assisted` | История, пересчёт статистики |
| `exerciseAttempts` | `id`, `type`, `wordId`, `correct`, `assisted`, `answer`, `at` | Статистика упражнений |
| `writing` | `char`, `stage` (`watched`/`traced`/`free`), `mistakes`, `completedAt` | Прогресс письма |
| `settings` | ключ-значение | Показ пиньиня, скорость, демо-флаг |

Экспорт: JSON со всеми таблицами + `schemaVersion` + дата. Импорт проверяет версию и не дублирует записи (по `id`).

## Модули `web/src`

| Модуль | Что внутри | Тесты |
|---|---|---|
| `domain/pinyin` | нормализация ввода, сравнение слога и тона отдельно | юнит |
| `domain/scheduling` | обёртка ts-fsrs, очередь «ошибки → просроченные → сегодня» | юнит |
| `domain/exercises` | генерация вариантов и разборов из данных слов | юнит |
| `domain/search` | индекс словаря: иероглиф, пиньинь (с тонами/цифрами/без), русский | юнит |
| `data/` | загрузка `hsk1.json`, Dexie, экспорт/импорт | юнит |
| `features/*` | экраны | e2e (Playwright) |
| `ui/` | токены и компоненты | визуальная проверка |

## Определения

- **Изучено слово** — слово хотя бы раз оценено в карточках или упражнении.
- **Закреплено** — для прототипа: состояние FSRS «Review» и стабильность ≥ 7 дней. Порог настраивается.
- **Повторы на сегодня** — карточки с `due` ≤ конец текущего дня по часовому поясу устройства.
