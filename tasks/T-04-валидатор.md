# T-04. Валидатор данных

**День:** воскресенье 8.11 · **Разработчик:** Claude Code · **Ревью:** Codex · **Время:** 1–2 ч

## Зачем
Защита от ошибок контента без участия человека: любая сломанная запись останавливает сборку.

## Что сделать
`content/scripts/validate.py` — проверяет `content/data/*.json` и выводит понятный отчёт на русском. Код выхода ≠ 0 при любой ошибке.

Проверки:
1. Контрольные числа 300 / 246 / 100 и совпадение `id` с индексом `docs/source/data/06-source-reference-index.csv`.
2. Уникальность `id` и официальных номеров.
3. Пиньинь: только допустимые слоги китайского (таблица слогов), тоны 1–4 и нейтральный; `pinyinNumeric` соответствует `pinyin`.
4. Сверка пиньиня с pinyin-pro (или pypinyin): **расхождения — предупреждение, не ошибка** (из-за 多音字 и сандхи); список предупреждений в отчёте для учителя.
5. Если поля уже есть: `meaningsRu` не пустые, `meaningRuShort` ≤ 25 символов, файл `audio` существует и не пустой.
6. Статусы только из разрешённого списка.

Подключить: в GitHub Actions — запуск `validate.py`; в `CLAUDE.md` §6 команда уже указана.

## Критерии приёмки
1. На текущих данных: 0 ошибок (предупреждения допустимы и перечислены).
2. Тесты: для каждой проверки — пример сломанных данных, на котором валидатор падает с понятным сообщением.
3. GitHub Actions запускает валидатор.
