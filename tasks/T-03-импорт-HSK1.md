# T-03. Импорт HSK 1 из официального PDF

**День:** воскресенье 8.11 · **Разработчик:** Claude Code · **Ревью:** Codex · **Время:** 3–4 ч
⚠️ Главный технический риск недели (R-02). Сигнал тревоги — нет 300 слов к 13:00.

## Зачем
Все слова и знаки должны соответствовать официальной программе HSK 3.0, а не случайному списку из интернета.

## Входные данные
- URL и SHA-256 PDF: `docs/source/data/08-source-manifest.json` (файл `syllabus.pdf`, 406 страниц).
- Индекс для сверки: `docs/source/data/06-source-reference-index.csv` (`reference_id`, `kind`, `level`, `pdf_page`, `source_locator`).
  - `vocabulary_row`, level `1`: 300 строк, `reference_id` вида `HSK-V00001`, `source_locator` = `official_serial:N`, страницы 80–87.
  - `character_recognition`, level `1`: 246 строк, страницы 356–357.
  - `character_handwriting`, level `1-2`: 100 строк, страница 377.
- Нумерация страниц — **физическая** (обложка = 1).

## Что сделать
1. `content/scripts/download_sources.py`: скачать PDF в `content/sources/`, проверить SHA-256 с манифестом. Несовпадение → остановка с понятной ошибкой.
2. `content/scripts/import_hsk1.py` (pdfplumber):
   - слова уровня 1: официальный номер, слово (иероглифы), пиньинь, часть речи, скобочные пометы **без потерь** (в `sourceNote`), страница;
   - разделять строки по **колонке уровня**, а не только по странице (на стр. 87 может начинаться уровень 2);
   - 246 знаков узнавания уровня 1 и 100 знаков письма группы 1–2 с номерами;
   - водяные знаки PDF не должны попасть в данные.
3. Результат: `content/data/hsk1.raw.json` по формату `docs/10-архитектура.md` (без русских значений и аудио).
4. Отчёт сверки `content/review/import-report.md`: количество, пропущенные номера, дубликаты, пустые поля, спорные строки.
5. Для 20 случайных слов и 10 знаков — сохранить картинки соответствующих мест PDF в `content/review/import-samples/` для визуальной сверки (владельцем и Claude в проекте).

## Критерии приёмки
1. Ровно **300** слов, **246** знаков узнавания, **100** знаков письма.
2. `id` каждого элемента совпадает с `reference_id` индекса; номера 1…N без пропусков и повторов.
3. У каждого слова есть иероглифы и пиньинь с диакритикой; в пиньине только допустимые символы.
4. Каждый иероглиф слов HSK 1 встречается в списке знаков узнавания (если нет — список исключений в отчёте, это допустимо, но должно быть видно).
5. Повторный запуск даёт тот же результат (детерминированность).
6. Тесты на парсер для нескольких «трудных» строк (многозначные пометы, переход страниц).
