# T-01. Установка инструментов

**День:** суббота 7.11, утро · **Делают:** вы + Claude в проекте · **Время:** 2–3 ч

## Зачем
Без установленных инструментов ни одна задача не начнётся.

## Что сделать
Пройти `docs/04-установка.md`, шаги 1–8.

## Критерии приёмки
1. `node --version` ≥ 20, `python3`, `git`, `gh` отвечают версией.
2. `claude` и `codex` запускаются и вошли в аккаунты.
3. Репозиторий `chine-course` создан на GitHub (приватный), стартовые файлы в нём.
4. Аккаунт Cloudflare создан.
5. Claude Code правильно пересказал правила проекта (шаг 8).

## Чек-лист владельца
- [ ] Все команды шага 2 показали версии.
- [ ] На github.com виден репозиторий с папками `docs`, `tasks`, `prompts`.
- [ ] Claude Code пересказал проект верно.

## Если не получается
Присылайте в проект номер шага, команду и полный текст ошибки. Не переустанавливайте ничего наугад.
