# T-07. Дизайн-система, навигация, главная

**День:** понедельник 9.11 · **Разработчик:** Claude Code · **Ревью:** Codex · **Время:** 2–3 ч

## Зачем
Руководство школы будет оценивать в первую очередь аккуратность и понятность.

## Что сделать
1. Токены в `web/src/ui/tokens` из `docs/source/ТЗ-дизайн.md` §3–4: цвета (светлая тема), размеры текста, отступы (сетка 4: 8/12/16/24/32), радиусы (кнопка 16, карточка 20), высота кнопки 52, зона нажатия ≥ 48.
2. Шрифты: системные; для китайского — стек PingFang SC, Noto Sans SC, Microsoft YaHei, sans-serif + `lang="zh-CN"`.
3. Базовые компоненты: Button (основная/вторичная), Card, Badge статуса (цвет + значок + текст), ChineseText (размеры: слово/знак/в предложении), Pinyin, ProgressBar, EmptyState, ErrorState.
4. Нижняя навигация: **Главная · Карточки · Практика · Словарь · Прогресс** (иконка + подпись). Внутри упражнения навигация скрыта, выход — крестиком.
5. Главная: заголовок «Китайский · HSK 1», карточка «Продолжить» (основная кнопка), «Повторов на сегодня: N», плитки разделов. Пока данные — заглушки из одного места, которые T-08 заменит реальными.
6. Адаптивность: телефон (поля 16–20), компьютер (учебная колонка ≤ 680 по центру).

## Критерии приёмки
1. Все цвета и размеры — из токенов (в компонентах нет «сырых» цветов).
2. Контраст обычного текста ≥ 4,5:1 (проверить автоматически, например axe в e2e).
3. При системном увеличении текста до 200% нижняя навигация и кнопки не обрезаются.
4. e2e: переход по всем 5 разделам на мобильном и десктопном размере.

## Чек-лист владельца
- [ ] На телефоне: аккуратно, ничего не налезает, кнопки легко нажать пальцем.
- [ ] На компьютере: содержимое по центру, не растянуто на весь экран.
- [ ] Иероглифы выглядят как китайские (сравните 直 и 骨 с тем, как их пишет учитель).
