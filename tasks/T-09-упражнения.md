# T-09. Упражнения (3 типа)

**День:** вторник 10.11 · **Разработчик:** Claude Code · **Ревью:** Codex · **Время:** 3–4 ч

## Зачем
Самостоятельная проверка знаний с мгновенным разбором — без учителя и без ИИ.

## Что сделать
Правила генерации и проверки — `docs/01-ТЗ-прототипа.md` §5.

1. `domain/pinyin`: нормализация ввода (`ni3`→`nǐ`, `nv3`/`nu:3`→`nǚ`, регистр, пробелы, апостроф, нейтральный тон `5`/`0`/без цифры); сравнение **по слогам**: слог верный / тон верный отдельно.
2. `domain/exercises`: генераторы трёх типов, неверные варианты без дубликатов и без правильного ответа среди них; разбор из шаблонов.
3. Экран «Практика»: сессия из 10 заданий, смешанные типы, приоритет — слова, которые ученик уже видел в карточках.
   - **Иероглиф → значение** и **значение → иероглиф**: 4 варианта; до проверки выбор выделяется нейтрально; кнопка «Проверить»;
   - **Ввод пиньиня**: поле ввода, подсказка «тоны цифрами: ni3 hao3», клавиатура не закрывает поле и кнопку;
   - **Выбор тона**: иероглиф + слог без тона + ▶; 5 вариантов (1–4 + нейтральный); только для односложных слов.
4. После проверки: вывод (верно/неверно — цвет **и** значок **и** текст) → причина → правильный ответ → «Далее».
5. Кнопка «Подсказка» (показать пиньинь) → ответ «с помощью», в повторении не считается полным успехом.
6. Результаты упражнений обновляют расписание карточек (верно без помощи = «Помню», неверно = «Не помню»).
7. Итог сессии: X из 10, список слов с ошибками + кнопка «Повторить ошибки».

## Критерии приёмки
1. Юнит-тесты нормализации: не меньше 30 случаев, включая ü, нейтральный тон, двусложные слова, лишние пробелы, неверный тон при верном слоге.
2. Юнит-тесты генераторов: 1 000 сгенерированных заданий — ни одного с дубликатами вариантов или двумя верными ответами.
3. e2e: пройти сессию, ошибиться, увидеть разбор, итог и «Повторить ошибки».

## Чек-лист владельца
- [ ] Ввод `ni3 hao3` для 你好 — засчитано.
- [ ] Ввод `ni2 hao3` — «слог верный, тон неверный».
- [ ] Нарочно выберите неверное значение — разбор понятен.
- [ ] На телефоне клавиатура не закрывает поле ввода.
