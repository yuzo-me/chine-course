# T-15. Стабилизация и проверка на устройствах

**День:** четверг 12.11, после 12:00 · **Делают:** вы (проверка) + Claude Code (исправления) · **Приёмка:** Claude в проекте

## Правило
**Заморозка функций.** Только исправления ошибок. Любое «а давай ещё добавим» — в список на после показа.

## Что сделать
1. Вы проходите таблицу `docs/05-чек-листы.md` §2 на всех устройствах.
2. Каждая ❌ → `prompts/сообщить-об-ошибке.md` → исправление в ветке `fix/…` → ревью Codex (кратко) → слияние.
3. Claude Code: полный прогон всех тестов, проверка размера сайта и скорости открытия; отчёт «Известные ограничения».
4. Финальная версия в `main`, тег `v0.1-prototype`.
5. Запись экрана демо-сценария (`docs/09-демо-и-презентация.md`) на телефоне — резервная копия на случай проблем.
6. Claude в проекте: итоговый текст слайдов по фактическому результату.

## Критерии приёмки
1. Все пункты таблицы устройств ✅ или осознанно отложены с записью в «Известные ограничения».
2. Тег `v0.1-prototype` на GitHub, сайт по ссылке соответствует ему.
3. Запись экрана есть.
4. Две репетиции показа проведены.
