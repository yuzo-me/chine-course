# T-10. Словарь и поиск

**День:** вторник 10.11 · **Разработчик:** Claude Code (если у него лимит — Codex по `prompts/codex-задача.md`) · **Ревью:** другая модель · **Время:** 2 ч

## Зачем
Быстро найти слово, услышать его и добавить в карточки.

## Что сделать
1. `domain/search`: индекс по иероглифам, пиньиню (с диакритикой, с цифрами, без тонов), русским значениям (с учётом начала слова и регистра).
2. Ранжирование: точное совпадение → начинается с → содержит.
3. Экран «Словарь»: поле поиска, результаты при вводе, пустой результат — «Ничего не найдено. Проверьте ввод: пиньинь можно писать цифрами — ni3».
4. Статья слова: иероглифы (крупно), пиньинь, часть речи, значения, ▶, уровень HSK 1, анимация черт каждого знака (если T-11 уже готова — ссылка «Написать»), кнопка «Учить в карточках» (ставит слово в новые первым).
5. Если поиск без тонов даёт несколько слов — показать все, не выбирать одно.

## Критерии приёмки
1. Юнит-тесты: 你, `ni`, `nǐ`, `ni3`, «ты», «Ты», «спасиб» находят ожидаемые слова.
2. Поиск по всем 300 словам ≤ 300 мс (тест производительности на данных).
3. Работает без сети.
