# T-13. Прогресс, офлайн, резервная копия

**День:** среда 11.11 · **Разработчик:** Claude Code · **Ревью:** Codex · **Время:** 2–3 ч

## Что сделать
1. Экран «Прогресс» (определения — `docs/10-архитектура.md` «Определения»):
   - изучено слов (из 300), закреплено, повторов на сегодня;
   - упражнения: решено, процент верных без подсказки;
   - письмо: знаков пройдено «без контура» (из 100);
   - каждое число с короткой подписью «как считается» (по нажатию);
   - график не обязателен; если есть — с текстовым представлением.
2. PWA: все файлы сайта, данные и аудио кэшируются; иконка и название для экрана «Домой»; сообщение «Доступно обновление — обновить» при новой версии.
3. Настройки: экспорт прогресса (JSON-файл с датой в названии), импорт (проверка версии, без дублей, подтверждение перед заменой), «Сбросить прогресс» с подтверждением.
4. Подсказка на iPhone: «Чтобы прогресс не потерялся, добавьте сайт на экран „Домой“» (один раз, можно закрыть).

## Критерии приёмки
1. В режиме полёта после одного онлайн-открытия: сайт открывается, карточки, упражнения, словарь, письмо, звук работают.
2. Экспорт → сброс → импорт возвращает тот же прогресс (e2e или юнит-тест на уровне данных).
3. Числа прогресса совпадают с реальными действиями (тест: сделать 5 карточек → «изучено 5»).

## Чек-лист владельца
- [ ] Установить сайт на экран «Домой» на iPhone; включить режим полёта; открыть — всё работает, звук играет.
- [ ] Экспорт → «Сбросить» → импорт — прогресс вернулся.
