# T-05. Русские значения слов

**День:** воскресенье 8.11 · **Разработчик:** Claude Code · **Ревью:** Codex, затем учитель (вторник) · **Время:** 1–2 ч

## Зачем
Ученику нужно русское значение каждого слова. ИИ используется только здесь — на этапе подготовки; на сайт попадают готовые проверенные данные.

## Что сделать
1. Сгенерировать значения по `prompts/контент-русские-значения.md` → `content/data/hsk1.meanings.json`.
2. `content/scripts/build.py`: объединить `hsk1.raw.json` + `hsk1.meanings.json` (+ позже аудио и правки учителя) → `content/data/hsk1.json`. Исходные файлы не перезаписываются.
3. Всем значениям статус `generated`; слова с низкой уверенностью помечены.
4. Запуск `validate.py` на итоговом файле.

## Критерии приёмки
1. У всех 300 слов есть `meaningsRu` (1–3) и `meaningRuShort` (≤ 25 символов).
2. Служебные слова имеют пояснение функции в скобках.
3. Список слов с низкой уверенностью — в отчёте.
4. `build.py` детерминирован, валидатор без ошибок.
5. **Ревью Codex:** выборка 30 случайных слов — независимая оценка значений; спорные — в ревью.

## Чек-лист владельца
- [ ] Откройте `content/data/hsk1.json` (или попросите Claude Code показать первые 20 слов таблицей) — значения понятны.
- [ ] Список «низкая уверенность» — не больше ~10% слов.
