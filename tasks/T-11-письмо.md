# T-11. Письмо иероглифов

**День:** среда 11.11 · **Разработчик:** Claude Code · **Ревью:** Codex + учитель (вечер среды) · **Время:** 3–4 ч
⚠️ Риск R-07.

## Зачем
Письмо иероглифов — ключевой навык; проверка черт выполняется алгоритмом сравнения с эталоном (не ИИ).

## Что сделать
1. hanzi-writer + данные черт **локально** только для нужных знаков (100 знаков письма группы 1–2 + знаки 300 слов), чтобы работало офлайн. Источник и лицензия данных — в отчёт и `docs/08-лицензии.md`.
2. Раздел письма (вход из главной и из статьи словаря), список 100 знаков письма группы 1–2 с отметкой пройденных.
3. Экран знака, этапы с явными подписями:
   1) «Смотреть» — анимация черт, повтор;
   2) «С контуром» — `quiz` с видимым контуром;
   3) «Без контура» — `quiz` без контура.
   Кнопки: «Показать», «Начать заново». Холст ≥ 240×240, квадратная сетка 米字格.
4. Ошибка черты: подсветка правильной черты и текст «Черта №N: начните сверху» (по данным направления); после 3 ошибок подряд — показать черту.
5. Сохранение этапа и числа ошибок в таблице `writing`.
6. На телефоне холст не прокручивает страницу при рисовании.
7. Знаки, для которых нет данных черт, — список в отчёте; в интерфейсе для них этап письма недоступен с пояснением.

## Критерии приёмки
1. Все 100 знаков группы 1–2 имеют данные черт (или явный список исключений).
2. Работает пальцем (iPhone, Android) и мышью.
3. Офлайн работает.
4. e2e: открыть знак, пройти анимацию, перейти к этапам (рисование имитировать, если возможно; иначе — ручная проверка в чек-листе).

## Чек-лист владельца и учителя
- [ ] Учитель пишет 10 знаков (人, 大, 口, 日, 月, 我, 你, 好, 中, 国) с контуром и без — ложных ошибок почти нет.
- [ ] Неверный порядок черт → понятная подсказка.
- [ ] При рисовании страница не прокручивается.
