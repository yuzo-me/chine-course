# T-08. Карточки и повторение, хранение прогресса

**День:** понедельник 9.11 · **Разработчик:** Claude Code · **Ревью:** Codex · **Время:** 3–4 ч

## Зачем
Ядро тренажёра: ученик учит слова, а приложение само решает, что и когда повторить.

## Что сделать
1. Загрузка `content/data/hsk1.json` и аудио в сборку сайта.
2. Dexie: таблицы `cards`, `reviewLog`, `settings` по `docs/10-архитектура.md`.
3. `domain/scheduling`: обёртка ts-fsrs; оценки «Не помню / Трудно / Помню / Легко» = Again / Hard / Good / Easy; очередь: ошибки текущей сессии → просроченные → на сегодня → новые (по официальному порядку, порция новых за сессию — настройка, по умолчанию 10).
4. Экран «Карточки»:
   - лицевая сторона: иероглифы (направление «иероглиф → значение») или значение (направление «значение → иероглиф»);
   - кнопка «Перевернуть» (+ нажатие на карточку как дополнительный способ);
   - оборот: иероглифы, пиньинь, значение, ▶ озвучка;
   - **озвучка отдельной кнопкой и не переворачивает карточку**;
   - после переворота — 4 подписанные кнопки оценки;
   - анимация 180–240 мс; при «уменьшении движения» — без анимации;
   - «Не помню» → карточка возвращается в этой же сессии;
   - конец сессии: «Сегодня: N слов, M новых» + кнопка «Ещё».
5. Главная показывает реальное число повторов на сегодня.
6. Скрытая сторона карточки недоступна экранному диктору до переворота.

## Критерии приёмки
1. Юнит-тесты планировщика: порядок очереди; «Не помню» возвращает в сессию; дата следующего повтора растёт при «Помню»/«Легко».
2. Прогресс сохраняется после перезагрузки страницы.
3. Повторное нажатие оценки не создаёт двойную запись в `reviewLog`.
4. e2e: пройти 5 карточек, перезагрузить, увидеть корректное число повторов.
