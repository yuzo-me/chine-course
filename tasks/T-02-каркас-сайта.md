# T-02. Каркас сайта, автопроверки, публикация

**День:** суббота 7.11 · **Разработчик:** Claude Code · **Ревью:** Codex · **Время:** 2–3 ч

## Зачем
Рабочая основа, на которую ложатся все остальные задачи, и постоянная ссылка, по которой сайт обновляется сам.

## Что сделать
1. В `web/` создать проект React + TypeScript + Vite (strict TS).
2. Подключить: ESLint, Vitest, Playwright (chromium + webkit), Dexie, vite-plugin-pwa (пока минимально), React Router.
3. Скрипты в `web/package.json`: `dev`, `build`, `preview`, `lint`, `typecheck`, `test`, `test:e2e`.
4. Каркас папок `web/src` по `CLAUDE.md` §5 и пустой экран «Китайский · HSK — скоро здесь будет тренажёр» на русском.
5. В `content/` — папки `sources/`, `scripts/`, `data/`, `audio/`, `review/`; `content/requirements.txt` (pdfplumber и др.), инструкция создания `.venv` в `content/README.md`.
6. GitHub Actions: при push и pull request — `lint`, `typecheck`, `test`, `build` для `web/`.
7. Помочь владельцу подключить Cloudflare Pages к репозиторию: **пошаговая инструкция с указанием, что нажимать** (сборка из `web/`, команда `npm run build`, папка `dist`, ветка `main`; предпросмотр для веток).
8. Одна юнит-проверка и один e2e-тест «главная открывается и показывает заголовок».

## Критерии приёмки
1. Все команды из `CLAUDE.md` §6 (кроме validate) проходят.
2. GitHub Actions зелёный.
3. Сайт открывается по постоянной ссылке `*.pages.dev` на телефоне владельца.
4. Нет зависимостей, не перечисленных в `CLAUDE.md` §4, кроме инструментов разработки (eslint и т. п.) — они перечислены в отчёте.

## Чек-лист владельца
- [ ] На github.com во вкладке Actions — зелёная галочка.
- [ ] Ссылка `….pages.dev` открывается на телефоне и показывает заголовок.
- [ ] Ссылка открывается на компьютере.
